# Yamone Korean

Offline-first Korean learning app for non-Korean speakers.

## Product direction

- Android / Jetpack Compose
- No server, account, or login required
- Local-only learning progress and settings
- Learning flow: Hangul jamo -> touch writing -> syllables/words -> sentences -> listening -> speaking
- Explanation languages: English, Spanish, French, Vietnamese, Thai, Indonesian
- Persistent banner ad area during learning screens
- Rewarded ads are intentionally excluded from the first release
